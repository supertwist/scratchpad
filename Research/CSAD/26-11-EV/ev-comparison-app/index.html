Methodology

This comparison tool uses data from the gaia-charge/evdb project, which provides an open-source database of electric vehicle specifications.

Data Sources

  • gaia-charge/evdb GitHub repository
  • Manufacturer specifications and official documentation
  • Independent testing and real-world data

Data Collection Process

The database collects information from multiple sources including manufacturer specifications, independent testing organizations, and real-world performance metrics. Data is verified and updated regularly.

Calculations

  • Range: Calculated based on WLTP (Worldwide Harmonized Light Vehicle Test Procedure) or EPA standards where available
  • Efficiency: Measured in kWh per 100 km
  • Charging Time: Indicates time to charge from 10% to 80%

Citations

All vehicle specifications are cited from their official sources. For more information, see the gaia-charge/evdb GitHub repository and their documentation.

About This Project

This electric vehicle comparison tool has been created to help consumers make informed decisions about electric vehicle purchases by providing a simple interface to compare key specifications.

The application uses real-time data from the gaia-charge/evdb open-source database of electric vehicles.

Data Accuracy

Please note that vehicle specifications may change over time. This tool provides the most current available data from official sources.

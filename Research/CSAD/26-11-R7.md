# Rhino 7 GPU Rendering on M2 Ultra

## Problem
Rhino 7 cannot access GPU for Cycles rendering on M-series Macs (M2 Ultra, M1, M3, etc.).

## Root Cause
Rhino 7 runs under **Rosetta 2 emulation** on Apple Silicon. This Intel-to-ARM translation layer does not support native Metal GPU acceleration, forcing Cycles to fall back to CPU-only rendering.

This is an **architectural limitation**, not a configuration issue—no settings will enable GPU rendering in Rhino 7.

## Solution
**Upgrade to Rhino 8**, which was built natively for Apple Silicon from the start.

### Rhino 8 Benefits
- Full Metal GPU support for Cycles rendering
- Significantly faster rendering on M2 Ultra
- Metal-based display (faster viewport interaction)
- Native Apple Silicon optimization

## Confirmation
This is a documented limitation confirmed by McNeel (Rhino's developer) across multiple forum threads. Users with M1/M2/M3 chips running Rhino 7 consistently report the same issue and receive the same recommendation: upgrade to Rhino 8.
